# Disc Bag Advisor - one-page summary

**Purpose and interface.** Fieldwork recommends possible additions to a disc golf bag by named disc, multiple reference discs, or flight category. Responsive desktop/mobile controls support strict brand preferences, sorting, manufacturer photos, a saved bag, and directional refinement. Sorting appears above brands; five defaults and Show more expose all 20 manufacturers in the linked DiscList snapshot. The seed catalog contains 37 source-linked discs.

**Agent framework.** FastAPI serves the interface. A custom bounded asyncio orchestrator uses OpenAI Responses (gpt-5-mini by default) to select search and rank tools from the official MCP SDK's local stdio server. The host enforces catalog identity, brand/sort/bag constraints, call budgets, and deadlines. Labeled deterministic MCP fallback handles supported searches when OpenAI fails. AGENT_FRAMEWORK.md documents the execution graph and controls.

**DiscFinder on View disc.** Clicking a result independently connects to https://finder.golfwithdiscs.com/mcp over real Streamable HTTP MCP, discovers and calls find_retailer_stock, and displays source-returned stock, retailer prices, variants, country/currency context, and purchase links. Country changes and refresh perform new lookups. DiscFinder is the sole stock source: no web-search, model-knowledge, or alternate-provider substitute is used. The endpoint was also registered in Codex; the app does not depend on Codex's native connector reload.

**Recovery and provenance.** Manufacturer imagery and stock load independently. Manufacturer failures retain source links and cached image fallback. DiscFinder outages, unknown discs, or no offers show explicit messages without invented or stale stock. Only validated HTTPS retailer links and plain text are rendered; source affiliate disclosures are preserved. Prices/stock are source-reported and should be confirmed at checkout. Shipping and checkout charges are excluded. No purchase is performed.

**Records and validation.** WORK_LOG.md records implementation. UUID-linked JSON records retain recommendation and stock modes, inputs, source/tool, timestamps, results, statuses, and timings; SQLite stores local selection popularity and image-cache URLs. Twenty-three automated checks passed, including remote-client dispatch, stock failure paths, HTTPS link validation, real local MCP, and OpenAI error handling. Live DiscFinder discovery and find_retailer_stock calls passed; browser checks cover View disc, country switching, mobile layout, and no-substitute outages.

**Launch and scope.** DiscBag owns its Python runtime and packages under .runtime, independently of other project folders. Run ./start.cmd and visit http://127.0.0.1:8010. OpenAI uses this folder's ignored .env; the tested public DiscFinder calls need no API key. The app is local and single-user; no internet deployment is claimed. Source: https://github.com/dougwalkerextension-sketch/disc-bag-advisor.
